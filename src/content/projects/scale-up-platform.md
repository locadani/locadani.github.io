The most interesting piece is a product agent: an interactive 3D machine model paired with
a retrieval-augmented agent that answers questions grounded strictly in the components the
user can actually see, by filtering the source CAD data down to the visible model.

Also includes geographic and graph visualisations, generated PDF reports, and load testing
with k6.
